## Handoff

Done in statewalker/.github#6 (squash-merged as 4c75abc).

The shared `ci.yml` has two new opt-in inputs (both default `false`) and a profile input:

- **`package-checks: true`** runs `scripts/check-package-tools.mjs`. Each public package is packed as `pnpm publish` packs it, then:
  - publint runs on it, and its errors fail;
  - attw runs on it with `attw-profile` (default `esm-only`; `node16` and `strict` are the other choices).
- **`api-diff: true`** runs `scripts/check-api-diff.mjs`. Each package's packed type declarations are compared with npm's `latest`, entry point by entry point (`exports`, resolved in bundler mode).
  - **Breaking:**
    - an entry point removed, or left without types;
    - an export removed;
    - an export that stops being a value (`export type { X }` included) or a type;
    - a public or protected member removed from an exported class, interface or enum.
  - **Fails** unless a changeset or a version bump past npm declares the bump the change needs: major from 1.0, minor on 0.x, patch on 0.0.x.
  - **Limits:** additions are listed only; packages not on npm are skipped; signature changes are not compared (the README says so).
- **Tools:** publint 0.3.25, attw 0.18.5 and TypeScript 5.9.3 are pinned in `.github`'s lockfile. The workflow installs them only when a switch is on.
- **Fixtures:** `fixtures/package-tools/*` and `fixtures/api-diff/*` (13 cases), run by `pnpm test` in the self-test CI.
- **Merge gate:** 1 pass. 0 critical; 2 high, both fixed in the pull request (private members counted as API; `export type` not seen as dropping a value). No follow-up issues.
