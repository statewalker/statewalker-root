## Handoff

Done in statewalker/.github#5 (squash-merged as 639e621).

- **Switch:** the shared `ci.yml` has a new `baseline` input, which can be `off` (the default, today's behaviour), `library` or `app`. A project opts in with `with: { baseline: library }`. The rollout is statewalker/statewalker-root#29.
- **The check:** `scripts/check-scripts.mjs <library|app>` runs right after the install when the baseline is on. It fails CI when:
  - a required root script is missing (library: `lint:check`, `format:check`, `build`, `typecheck`, `test`; app: `build`, `typecheck`);
  - a root `pnpm -r run X` runs nothing because no package defines X;
  - root `typecheck` delegates to packages and a package with a `tsconfig.json` has no `typecheck` script;
  - a TypeScript test file (`*.test.*` / `*.spec.*`, in packages or at a monorepo's root) is in no tsconfig that a typecheck step compiles. The check uses `tsc --listFilesOnly` and follows `references`.
- **Required steps:** with the baseline on, the required steps run without `--if-present`, and root `typecheck:tests` runs after `typecheck` when it exists.
- **Self-test:** `.github` now has its own CI (`self-test.yml`). `pnpm test` runs the check against fixture repositories in `fixtures/check-scripts/`: a clean library, a clean app, and the defect cases. actionlint lints the workflows.
- **Merge gate:** 1 pass. 0 critical; 2 high, both fixed in the pull request (`pnpm -r exec tsc` was wrongly rejected; root tests of a monorepo were not scanned). No follow-up issues.
