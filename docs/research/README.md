# Research: Process and ecosystem

Research on the root's own subject, `process`: how others run reviews, CI and agent sessions.

- **One note per question.** Each note is a cited Markdown file, `<slug>.md`, linked from the
  `/research` or `wayfinder:research` ticket that asked it.
- **Notes merge through the session's pull request.** They don't go on a throwaway `research/*`
  branch, as the `wayfinder` skill says (`CLAUDE.md`, overrides).
- **Research on any other subject** goes to `subjects/<s>/research/<slug>.md` (`GLOSSARY-MAP.md`).
