# Subjects

One folder per subject: what it builds, its decisions, research, roadmap and handoff notes. The map
of subjects, their projects and how they relate is [`GLOSSARY-MAP.md`](../GLOSSARY-MAP.md). Its
machine-readable twin is [`subjects.json`](subjects.json). The `process` subject lives in
[`docs/`](../docs/process/README.md).

| Subject | Folder |
|---|---|
| Fragment platform | [`platform/`](platform/README.md) |
| AI harness | [`ai-harness/`](ai-harness/README.md) |
| Durable Objects runtimes | [`runtimes/`](runtimes/README.md) |
| Version control | [`vcs/`](vcs/README.md) |
| P2P and capabilities | [`p2p/`](p2p/README.md) |
| Sites and notebooks | [`sites/`](sites/README.md) |
| Product | [`product/`](product/README.md) |
| Data and storage | [`data/`](data/README.md) |

**Nothing here records state.** Run `node tools/status.mjs` for where each subject stands and what
comes next. [`docs/process/subjects.md`](../docs/process/subjects.md) explains the report, and how
to continue work and add a subject or a project.
