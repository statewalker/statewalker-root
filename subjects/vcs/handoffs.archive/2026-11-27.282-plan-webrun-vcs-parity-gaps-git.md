### Known pitfalls
- **`.tested/` conflicts.** A PR that reads "dirty" gets no CI runs. Fix it with `git checkout origin/main -- .tested`, then push. After each push, check that check runs actually started.
- **Idle children.** Nudge any child idle for over an hour with `send_message`.
